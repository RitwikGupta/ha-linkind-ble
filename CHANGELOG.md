# Changelog

## 0.1.0 — 2026-10-26

Initial experimental release for the Linkind HCRZ12FBM071:

- HA Bluetooth discovery with explicit model/address confirmation.
- Native activity event entity using local adapters or ESPHome proxies.
- Per-device repeat suppression and disabled cached advertisement replay.
- Privacy-conscious diagnostics, synthetic regression tests, and protocol notes.

Gesture commands, battery level, and on/off intent remain undecoded.
